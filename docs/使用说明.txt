WARP 新开关 · Windows 版 2.1.0
================================

适用于 64 位 Windows 10（1803 或更新）和 Windows 11。非官方客户端，与 Cloudflare 无隶属关系。
连接方式：usque（MASQUE over HTTP/2 + 伪装域名）+ sing-box（本机代理 127.0.0.1:7890）。


安装
----
1. 把整个「WARP 新开关」文件夹放到一个固定的位置（例如「文档」或 D:\Apps）。
   core 文件夹必须和 WARP 新开关.exe 放在一起。
2. 双击「WARP 新开关.exe」。
   如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
3. 第一次点「同意条款并注册」：程序会向 Cloudflare 注册你自己的免费 WARP 账号，然后自动连接。
4. 显示「已连接」后，浏览器等使用系统代理的程序就能用了。


日常使用
--------
- 开启 / 关闭：点窗口下方的大按钮。默认入口连不上时，会自动轮流试 8 个备用入口和「握手分片」，
  可能要一两分钟；窗口里会显示正在试第几种。连上后会记住，下次直接用。
- 伪装域名：窗口中间的输入框，默认 www.cloudflare.com。
  改完点「应用」或按回车，任何时候都能改。连接中应用只会重启隧道，不用先关闭。
- 网络诊断：在学校连不上时点它，大约半分钟出结论，会告诉你：
    · 是按 SNI 封锁（换伪装域名能解决），还是按 IP 封锁（换域名没用，要换网络）；
    · 哪些伪装域名在这个网络上真的能连上，点「使用 xxx」即可换上。
- 开机时自动连接：打开后，每次登录 Windows 都会在后台自动连接；
  睡眠唤醒、网络恢复后也会自动重连。手动点「关闭」后不会自动重连。
- 关掉窗口后程序仍在右下角通知区域运行（猫猫图标）。
  灰点 = 已关闭，蓝点 = 连接中，绿点 = 已连接，橙点 = 没连上。
- 退出：会先关闭连接、恢复原来的代理设置，再退出。


常见问题
--------
- 提示「系统正在使用另一个代理」：先关掉其他代理或翻墙软件，再点开启。
- 提示端口 7890 或 1080 被占用：常见是 Clash 等软件，关掉它再试。
- 连不上：先点「网络诊断」。点窗口里的「错误详情」可以看到并复制 usque 给出的完整错误。
  也可以点「打开日志」，查看 usque.log、sing-box.log、worker.log、diagnose.txt。
- 杀毒软件拦截 core 文件夹里的 usque.exe 或 sing-box.exe：这是开源的连接组件，需要放行。


卸载
----
1. 在程序里关掉「开机时自动连接」，然后点「退出」。
2. 删除「WARP 新开关」文件夹。
3. 在资源管理器地址栏输入 %LOCALAPPDATA%\WarpSwitchNext 并删除这个文件夹（里面是你的账号和日志）。


隐私
----
账号和日志只保存在本机 %LOCALAPPDATA%\WarpSwitchNext。
usque 4.2.1 保持服务器公钥校验开启。本机代理只监听 127.0.0.1。
伪装域名不能保证所有网络都能连接。请遵守适用的网络使用规则。
